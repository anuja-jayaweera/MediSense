# MediSense

MediSense is a Streamlit web application that helps users understand their medical reports in plain, easy-to-read language. Users can upload a medical report as a PDF or image, and the app uses Google's Gemini AI to generate a clear summary of the findings. A "Traffic Light" health dashboard highlights each test parameter as normal, borderline, or abnormal, and users can ask follow-up questions about their report through an interactive chat interface.

## Overview

Reading a medical report can be confusing without a medical background. MediSense bridges that gap by:

- Accepting a medical report upload in **PDF or image** format
- Extracting the text/data from the report
- Using **Google Gemini** to generate a plain-language summary of the results
- Presenting key parameters on a **color-coded "Traffic Light" dashboard** (parameter, value, unit, reference range, and status)
- Letting users **chat with the app** to ask follow-up questions about their report
- Providing a **dark-themed, interactive UI** for a smoother user experience

## Tech Stack

- **Frontend/App Framework:** [Streamlit](https://streamlit.io/)
- **AI Model:** Google Gemini (via `google-generativeai`)
- **PDF Processing:** PyPDF2
- **Image Processing:** Pillow (PIL)
- **Styling:** Custom CSS
- **Interactivity:** Custom JavaScript, injected via `streamlit.components.v1.html`

## How to Run

### Prerequisites

- Python 3.9 or higher
- A Google Gemini API key ([Google AI Studio](https://aistudio.google.com/))

### Steps

1. **Clone the repository**
   ```bash
   git clone https://github.com/anuja-jayaweera/MediSense.git
   cd MediSense
   ```

2. **Create and activate a virtual environment** (recommended)
   ```bash
   python -m venv venv
   source venv/bin/activate      # On Windows: venv\Scripts\activate
   ```

3. **Install dependencies**
   ```bash
   pip install -r requirements.txt
   ```

4. **Set up your Gemini API key**

   Set your API key as an environment variable:
   ```bash
   export GOOGLE_API_KEY="your_api_key_here"   # On Windows: set GOOGLE_API_KEY=your_api_key_here
   ```
   (Or configure it however `app.py` expects it, e.g. via a `.env` file or Streamlit secrets.)

5. **Run the app**
   ```bash
   streamlit run app.py
   ```

6. **Open the app**

   Streamlit will open the app automatically in your browser, or you can visit the URL shown in the terminal (typically `http://localhost:8501`).

## Usage

1. Launch the app and upload a medical report (PDF or image).
2. View the plain-language summary generated by Gemini.
3. Check the Traffic Light dashboard for a quick visual overview of each parameter's status.
4. Use the chat feature to ask any follow-up questions about your report.
